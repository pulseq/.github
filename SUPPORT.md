# Support

Pulseq repositories are community-supported open-source projects.

## Where to ask questions

Please use the most relevant repository for your question.

Examples:

- Use the MATLAB Pulseq repository for MATLAB implementation questions.
- Use the PyPulseq repository for Python implementation questions.
- Use specification, example, or validation repositories for cross-implementation issues, if available.

## Good support requests include

- what you are trying to do
- repository and version or commit
- operating system and relevant software versions
- minimal code or sequence example
- expected behavior
- observed behavior
- error messages or logs
- whether the issue affects MATLAB Pulseq, PyPulseq, or both

## Interoperability questions

For questions involving MATLAB/Python differences, file format compatibility, scanner interpretation, or cross-language examples, please label the issue clearly as an interoperability question.

## Safety-related questions

For scanner-specific safety, regulatory, clinical, or operational decisions, consult qualified local experts, institutional procedures, and vendor documentation. Pulseq community support does not replace scanner-specific safety review.

## Community discussions

Broader ideas, roadmap suggestions, workshop outcomes, and governance proposals should be raised through GitHub Discussions or issues in the appropriate repository.
