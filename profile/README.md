# Pulseq

Pulseq is an open ecosystem for vendor-neutral MRI sequence description, programming, validation, and exchange.

The Pulseq GitHub organization brings together related implementations and tools, including MATLAB Pulseq, PyPulseq, and supporting libraries, with the goal of enabling transparent, interoperable, reusable, and sustainable MRI sequence development.

## Organization principles

Pulseq repositories should support:

- **Open development** through GitHub issues, pull requests, reviews, and discussions.
- **FAIR software practices**: Findable, Accessible, Interoperable, and Reusable.
- **Cross-implementation coordination** between MATLAB Pulseq, PyPulseq, and related tools.
- **Distributed stewardship** so that projects do not depend on a single individual, laboratory, institution, or vendor.
- **Consensus before major stewardship changes**, including moving, renaming, archiving, transferring, or substantially restructuring repositories.
- **Small, reviewable pull requests** rather than large changes that are difficult for maintainers and contributors to evaluate.
- **Community-connected development**, where ideas from workshops, hackathons, user feedback, and scientific use cases are recorded and connected to development roadmaps.

## Repositories

Key repositories include:

- **MATLAB Pulseq** — MATLAB implementation and tools for Pulseq sequence development.
- **PyPulseq** — Python implementation and tools for Pulseq sequence development.
- **Supporting repositories** — examples, specifications, documentation, validation tools, and related projects as the ecosystem grows.

## Community

Pulseq welcomes contributors from MRI physics, engineering, computer science, clinical imaging, research, education, and open-source software communities.

Questions, feature ideas, interoperability concerns, and governance proposals should be raised openly whenever possible through GitHub issues, pull requests, or discussions in the relevant repository.
